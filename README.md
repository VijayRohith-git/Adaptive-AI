Adaptive UI AI Demo

This is a minimal demo that illustrates adaptive UI behavior driven by simple heuristics (a transparent, rule-based "AI").

Files
- index.html — demo page
- styles.css — styles
- app.js — lightweight adaptation logic and state persistence
- report_APA.md — APA-style report describing the work
- CHAT_HISTORY.md — saved assistant/user conversation

How to run
1. Open `index.html` in a modern browser.
2. Interact with the page to see adaptations (toggle theme, click, or just read for longer periods).

Notes
- The inference logic in `app.js` is intentionally simple and explainable. Replace with a learned model (e.g., TensorFlow.js) or a server-side model for more advanced behavior.
